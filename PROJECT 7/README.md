AI Analytics Analyzer
Description

This project is an AI-powered business analytics automation workflow built using n8n.

The workflow collects analytics requests, validates user input, generates AI-powered KPI insights and forecasting reports, creates professional HTML/PDF reports, and automatically sends reports through Gmail and Slack notifications.
